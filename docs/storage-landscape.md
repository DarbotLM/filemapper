# Storage landscape mapping

The overview uses the selected recorded snapshot and local service. At the root it shows up to 12 directory or reparse identities from the first 50 hierarchy entries, plus ranked file identities up to a combined maximum of 24. Inside a folder it shows distinct identities from the first 24 of the first 50 immediate entries. The caption reports the page size and total; File Explorer provides the full paged list. Aliases sharing a node ID collapse to one displayed identity. Recursive directory measurements can overlap shown files, so values should not be added.

Color indicates observed kind: teal file, gold directory, violet stream, gray reparse point, slate other. Voxel count represents an absolute band of the selected logical or allocated byte measurement: 0, 1–1,023 B, 1 KiB–<1 MiB, 1 MiB–<1 GiB, 1 GiB–<1 TiB, and at least 1 TiB use one through six voxels. Unknown measurements and integers outside the browser's exact range also use one voxel but are explicitly labeled unknown. These are visual bands, not proportional volume, learned semantics, or game shapes. Directory values are recursive measured scope and may be incomplete; unknown allocation stays unknown.

Selection uses the observed node ID and path. A `path-fallback:` node ID is path-derived and does not establish physical identity; stream IDs are derived and their parent physical identity may be unknown. Folder path drill and the local overview route retain the selected snapshot; snapshot root, recorded time, completeness, and service origin are shown. Exclusion policy is not included in the snapshot metadata available here. This is historical snapshot data, not a live filesystem assertion.
