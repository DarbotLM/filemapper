Links cover only the current result page and known distinct capture timestamps; the 180-link cap can omit valid pairs. Matching demonstrates equality of supplied fields, not ancestry, causation, time intervals, or semantic similarity. The checks do not establish browser rendering, live-reader integration, installed-app behavior, or performance on a real catalog. No browser preview or build was performed.

## Compare captures query

`mode=compare` pages matching editions in pinned catalog order. Each page row is the first matching stored row by SQLite `rowid` in that edition; this rule does not claim that the row is typical or the first in source order. `total` counts matching editions in this mode, while `occurrenceTotal` counts all matching observations and `matchingEditions` counts editions. Default `occurrences` mode retains occurrence pagination. Equal or unknown timestamp layers remain unlinked. Multiple editions of one capture can each contribute a representative.

An isolated Release service build using `work/dotnet11/dotnet.exe` and `work/observation-links-build` succeeded with zero warnings and errors. The native harness in `work/observation-compare-check/Program.cs` used copies of the SHA-pinned `single-head-bound-01` and `representative-head-bound-01` fixtures under `work/word-shape-swarm`. For shared exact word `1`, the reader returned 399 total occurrences across two matching editions; compare pages with limit one contained 1, 1, and 0 rows at offsets 0, 1, and 2, with distinct edition hashes. The default occurrence mode returned the same occurrence total. A missing term returned zero; a pre-canceled token raised cancellation. These checks do not prove mid-query cancellation timing or browser integration. No installed app or shared Debug build was used.
`nA query-ownership follow-up was checked with `work/observation-links-query-check.cjs` against the actual UI script in a controlled Node DOM/VM: 22 checks passed, including pagination after canceled and failed searches and a successful mode switch. The retained-page selection/toggle and late-response harness also passed again. These are not browser tests.
