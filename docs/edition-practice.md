# Edition-backed practice arena API

This optional practice mode freezes a single edition selected by SHA-256 from the connected public bank. It is not a held-out experiment, a semantic model, or a training operation. Playing an edition exposes its source for future evaluation; keep it out of any subsequently claimed unexposed test family. Existing evaluator protection registries and expert lineages are not updated by practice.

`GET /api/practice/editions?offset=0&limit=20` returns a page of `{edition,eligible,reason}`. Eligibility is preliminary: the edition must be at most 4 GiB and have an established non-fork family; freeze also validates the complete source, quotas and at least two complete words. The catalog pin must still be selected when freezing. Requests never contain edition filesystem paths. A catalog session and its read guards stay leased through freeze, including across reconnect. Paths and the internal computer-freeze request are not exported.

`POST /api/practice/arenas` (learn capability) accepts `{"editionSha256":"<lowercase SHA-256>","wordLimit":8,"pathLimit":2,"candidateLimit":2}`. Words must be 2–128, other quotas 0–128, and the sum at most 128. The response `{artifactHash,storedAt,arena}` contains a versioned practice schema, original request, public edition metadata, frozen challenge, deck availability/truncation summary, per-word source spans and an explicit practice scope. Path/candidate byte spans remain in piece evidence. No arbitrary policy is accepted. The challenge uses the existing native geometry and source-order rules. Saved bytes and hashes make replay independent of later catalog reconnect or edition availability.

`GET /api/practice/arenas` lists summaries and `GET /api/practice/arenas/{hash}` loads a saved arena (read). `POST /api/practice/replay` accepts `{arenaHash,moves}` and returns `{arenaHash,state,legalMoves,orientations}`. Moves carry `orientationId`, `x`, `z`, `layerId` and `expectedPriorStateHash`. `POST /api/practice/computer` accepts the same fields plus optional `budget`; it returns the existing bounded deterministic spatial-beam decision. It is not the reviewed expert policy. `POST /api/practice/episodes` accepts `{arenaHash,moves,competitor}` and saves a replayed record under `edition-practice-episode/1` (learn). The competitor is caller declared. Generic `/api/spatial-artifacts` listing and `/{hash}/export` expose saved records; load the parent arena and replay episode moves to reconstruct state.

Edition-practice freeze has a 180-second cooperative budget; other bounded arena operations retain 30 seconds. They share the existing two-operation limit and honor request cancellation. SQL source reads install SQLite interruption handlers; hashing checks cancellation between chunks. Persistence checks cancellation before transaction commit, but cancellation or disconnect can race the commit; an uncertain response may have committed an artifact. Refresh the saved-artifact list before retrying; identical content has the same hash. File guards depend on Windows filesystem sharing semantics. Game points and geometric buckets are not semantic accuracy, identity, reachability or vulnerability evidence; no game outcome becomes a learning label. Practice supports native beam only; it does not expose or import a trained expert checkpoint.
