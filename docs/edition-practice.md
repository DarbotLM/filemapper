# Edition-backed practice arena API

This optional practice mode freezes a single edition selected by SHA-256 from the connected public bank. Freezing and playing do not train a model. A separate explicit review operation can train an arena-bound imitation policy, as described below. Neither operation is a held-out experiment or semantic learning. Playing an edition exposes its source for future evaluation; keep it out of any subsequently claimed unexposed test family. Existing evaluator protection registries and protected expert lineages are not updated by practice.

`GET /api/practice/editions?offset=0&limit=20` returns a page of `{edition,eligible,reason}`. Eligibility is preliminary: the edition must be at most 4 GiB and have an established non-fork family; freeze also validates the complete source, quotas and at least two complete words. The catalog pin must still be selected when freezing. Requests never contain edition filesystem paths. A catalog session and its read guards stay leased through freeze, including across reconnect. Paths and the internal computer-freeze request are not exported.

`POST /api/practice/arenas` (learn capability) accepts `{"editionSha256":"<lowercase SHA-256>","wordLimit":8,"pathLimit":2,"candidateLimit":2}`. Words must be 2–128, other quotas 0–128, and the sum at most 128. The response `{artifactHash,storedAt,arena}` contains a versioned practice schema, original request, public edition metadata, frozen challenge, deck availability/truncation summary, per-word source spans and an explicit practice scope. Path/candidate byte spans remain in piece evidence. No arbitrary policy is accepted. The challenge uses the existing native geometry and source-order rules. Saved bytes and hashes make replay independent of later catalog reconnect or edition availability.

`GET /api/practice/arenas` lists summaries and `GET /api/practice/arenas/{hash}` loads a saved arena (read). `POST /api/practice/replay` accepts `{arenaHash,moves}` and returns `{arenaHash,state,legalMoves,orientations}`. Moves carry `orientationId`, `x`, `z`, `layerId` and `expectedPriorStateHash`. `POST /api/practice/computer` accepts the same fields plus optional `budget`; it returns the existing bounded deterministic spatial-beam decision. It is not the reviewed expert policy. `POST /api/practice/episodes` accepts `{arenaHash,moves,competitor}` and saves a replayed record under `edition-practice-episode/1` (learn). The competitor is caller declared. Generic `/api/spatial-artifacts` listing and `/{hash}/export` expose saved records; load the parent arena and replay episode moves to reconstruct state.

Edition-practice freeze has a 180-second cooperative budget; other bounded arena operations retain 30 seconds. They share the existing two-operation limit and honor request cancellation. SQL source reads install SQLite interruption handlers; hashing checks cancellation between chunks. Persistence checks cancellation before transaction commit, but cancellation or disconnect can race the commit; an uncertain response may have committed an artifact. Refresh the saved-artifact list before retrying; identical content has the same hash. File guards depend on Windows filesystem sharing semantics. Game points and geometric buckets are not semantic accuracy, identity, reachability or vulnerability evidence. Practice supports native beam and a separately reviewed arena-bound imitation policy; it does not import external or protected expert checkpoints.

## Explicit practice imitation

`GET /api/practice/policies` lists policy artifacts, and `GET /api/practice/policies/{hash}` replays and verifies the complete ancestry. `POST /api/practice/policies` with `{arenaHash}` creates a content-addressed zero-weight expert policy for that exact saved practice arena. `POST /api/practice/policies/train` accepts `{parentPolicyHash,episodeHash,reviewerId,reviewId,rationale,reviewedAt}` and performs one explicit reviewed imitation update. The saved episode must end the game and replay exactly against the same arena; a partial replay is ineligible. Review fields are nonblank, at most 512 characters, and may not contain control characters. `reviewedAt` is a non-default timestamp. Up to 32 updates may be linked, and an identical arena/trajectory cannot be reused under a different episode or competitor label. Parent ancestry, receipts and moves are reproduced before reuse; 30-second cooperative deadlines and cancellation bound each service operation.

A domain-separated, single-arena **practice-only** manifest satisfies the existing native expert learner's training input contract. It is not a protected evaluation cohort, evidence of held-out status, or permission to use an exposed source as a later test family. The adapter represents the submitted moves with an `unattested-practice-adapter` model marker and an `unattested-episode:` checkpoint marker. Competitor and reviewer identities and review rationale are caller declarations, not identity authentication or proof of independent review. The native receipt binds the actual parent model, replayed episode and candidate trace; the stored policy artifact binds the exact saved episode and previous policy artifact. Its verified reward is a game-rule calculation excluding advisory points and applying the native top-out penalty, not a semantic label or accuracy metric.

`POST /api/practice/policy-step` accepts `{arenaHash,policyHash,moves}` and returns `{stateHash,policyHash,modelHash,move,candidatesEvaluated}` for the existing native expert-ranking policy, with at most 64 sampled legal choices. The zero-weight initial policy and reviewed updates are distinct from the existing spatial-beam suggestion. No client-supplied weights, automatic training, or semantic learning is performed. A checked lineage establishes reproducible artifact ancestry and training calculation, not model usefulness, generalization, or a human's identity. Persistence checks cancellation before commit, but a disconnect can race a successful commit: refresh the saved-policy list after an uncertain response before retrying.
